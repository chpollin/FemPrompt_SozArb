Generated by `src/replay/prisma_flow.py` from the inputs listed in `prisma-flow.json`. Diagonal cells of a matrix give the distinct finds of one system.

Identity rule. Records are the same find when they share a normalised DOI, an arXiv id or a normalised title (transitively). Sources are processed in execution order; a find is a duplicate of an earlier source when it matches a record an earlier source transferred or a library item added before the source started.
