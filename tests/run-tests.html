PRISM pure-function tests (plan P1, browser runner)

Open this file from a local static server; no build step or framework is required. All fixtures are inline in tests.js. The runner loads the generated category schema, analysis vocabulary and seed, then evaluates the production logic without starting the application UI. Results render below, into document.title (PASS n/n or FAIL k/n), and into window.__TEST_RESULTS__, so a browser agent can read the outcome from the title alone.
